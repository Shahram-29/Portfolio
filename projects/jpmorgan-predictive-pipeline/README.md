# JPMorgan Chase (JPM) Strategic Analysis & Predictive Pipeline

Programming for Analytics — CA2. End-to-end analysis of JPM stock data: a reusable load-and-clean function (date normalisation, missing values), Augmented Dickey-Fuller stationarity testing, risk quantification, and a supervised linear-regression forecast evaluated on R².

**Notebook:** `JPM_Strategic_Analysis.ipynb` (pandas, numpy, statsmodels, scikit-learn, seaborn). Runs in Google Colab; expects the price CSV alongside the notebook.
