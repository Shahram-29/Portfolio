# Used Car Price Prediction

Applied Statistics & Machine Learning — CA2. Predicts used-car prices from listing data: cleaning and encoding, feature engineering (e.g. engine horsepower parsed from free-text specs), then an OLS linear-regression baseline (statsmodels) against a Support Vector Regressor tuned with GridSearchCV, evaluated on R² and RMSE.

**Script:** `used_car_price_prediction.py`.
