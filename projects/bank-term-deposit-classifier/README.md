# Bank Term-Deposit Classifier

Classification on the bank-marketing dataset: which customers subscribe to a term deposit? Binary mapping and dummy encoding of categorical fields, SMOTE class rebalancing, then Decision Tree, Random Forest and SVC models tuned with GridSearchCV and compared on accuracy and confusion matrices.

**Notebook:** `Bank_Term_Deposit_Classifier.ipynb` (pandas, scikit-learn, imbalanced-learn).
